# Локальные шрифты

Файлы поставляются без изменений и не требуют CDN:

- `Montserrat-Regular.otf`, `Montserrat-SemiBold.otf`: Montserrat 9.000,
  пакет Fedora `julietaula-montserrat-fonts-9.000-4.fc44`.
  Кириллица и латиница; лицензия `Montserrat-OFL.txt`.
- `NotoSansArmenian.ttf`: переменный Noto Sans Armenian,
  пакет Fedora `google-noto-sans-armenian-vf-fonts-20251201-2.fc44`.
  Исходное имя `NotoSansArmenian[wght].ttf`; армянские глифы,
  веса 100–900. Лицензия `NotoSansArmenian-OFL.txt` из
  <https://github.com/notofonts/armenian/blob/main/OFL.txt>.

Оба семейства распространяются по SIL Open Font License 1.1.
CSS выбирает Noto Sans Armenian для армянского и Montserrat для русского.
