# Роли и права на задачи

Роли — user и admin. Допущенный user читает доску и меняет статус собственных задач; admin меняет статус любой задачи и управляет допуском участников. Проверка прав выполняется на сервере, ограничения интерфейса не являются защитой.

Администратор одобряет и отклоняет заявки, блокирует и разблокирует участников. Переходы Pending / In Progress / Completed свободные, включая повторное открытие. Неизменяемый ID автора отделён от его отображаемого имени.
