# Одна команда и одна доска

BotFlow работает с одной командой и общей доской. Допущенные участники видят все задачи команды. Личные списки и несколько рабочих пространств не входят в текущую модель.

Единая доска делает авторство и права явными, не вводя выбор команды в каждом канале. Несколько команд потребуют отдельной модели членства и проверки изоляции данных.
