# React и TypeScript SPA

Веб-панель — React/TypeScript SPA на Vite. React Router отвечает за маршруты, TanStack Query — REST-данные и кеш, Material UI — интерфейс. SSR не требуется закрытой доске; готовая компонентная библиотека уменьшает объём собственного UI-кода.

Kanban содержит три колонки и явный переключатель статуса; на узком экране колонки вертикальны, drag-and-drop не вводится. Первоначально загружается до 50 карточек на колонку, новые сверху; история доступна через «Показать ещё». WS/REST-синхронизация не допускает дублей и старых версий между страницами.

Инструменты — Node 24 LTS, npm/package-lock, ESLint, Prettier, TypeScript, Vitest/React Testing Library и Playwright Chromium. Границы API и браузерные сценарии проверяются отдельно от компонентных тестов.

Интерфейс BotFlow использует белые/графитовые поверхности и золотистые акценты
предоставленного референса, с собственной темой MUI и без чужого брендинга.
Веб-панель полностью локализуется на русский и армянский, переключатель
«Русский / Հայերեն» сохраняет выбор локально; пользовательский текст не переводится.
Дизайн и проверяемые сценарии закреплены в [frontend-design](../frontend-design.md).
