# WebSocket-сигнал и REST-синхронизация

Tasks после commit публикует board.changed через Redis Pub/Sub. API передаёт сигнал WebSocket-подписчикам, а панель перечитывает REST. Изменения статуса остаются REST-командами; полный журнал событий для браузера не хранится.

Pub/Sub не воспроизводит пропущенное. Панель обновляется при reconnect, возврате на вкладку и каждые 30 секунд активной вкладки. Сигнал во время fetch требует следующего refresh, старый ответ не должен перезаписывать свежую версию. Цена — дополнительные REST-запросы.

Допуск проверяется через Identity при подключении и перед каждой защищённой отправкой подписчику. При отзыве сессии, блокировке или недоступном Identity новые данные не отправляются, соединение закрывается. Уже начатую отправку нельзя отозвать. WS не удерживает БД-сессию на всё время подключения.
