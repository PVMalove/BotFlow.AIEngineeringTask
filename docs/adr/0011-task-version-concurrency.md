# Версия задачи защищает конкурентные изменения

PATCH статуса передаёт status и expected_version. Проверка версии и изменение атомарны: устаревшая команда всегда получает 409, даже если целевой статус совпадает. При актуальной версии no-op возвращает 200 без увеличения версии и события; реальное изменение увеличивает версию.

После 409 панель перечитывает карточку и предлагает решить заново. При потерянном ответе также перечитывает данные и сообщает о неподтверждённом результате, без автоматического повторения команды. Отдельный Idempotency-Key для этой операции не вводится. Нужен интеграционный тест двух конкурентных DB-сессий.
