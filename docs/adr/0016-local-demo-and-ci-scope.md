# Локальная поставка и CI

BotFlow поставляется через Docker Compose с воспроизводимыми сборками и GitHub Actions CI. Локальный профиль доступен через localhost; адаптивность проверяется обычным и узким браузерным экраном. Внешний сервер, LAN-доступ и автоматическое серверное развёртывание не входят в этот профиль.

CI использует настоящие PostgreSQL, Redis, RabbitMQ и MinIO, а Telegram/Whisper подменяются на прикладных портах. Браузерные проверки используют реальный API в изолированном окружении. Отдельная живая проверка подтверждает Telegram, языки, качество, задержки и холодный старт; зелёный CI с подменами её не заменяет.
