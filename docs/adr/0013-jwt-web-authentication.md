# RS256 JWT и отзыв веб-сессий

После обмена одноразового кода Identity выдаёт RS256 JWT в HttpOnly cookie на 8 часов без refresh. Приватный ключ только у Identity; проверяющие сервисы получают публичный ключ. Identity хранит метаданные сессии и отзыв, не JWT целиком. Logout отзывает текущую сессию, block — все; unblock не оживляет их.

Подпись не заменяет актуальный допуск. Каждый новый защищённый запрос проверяется через Identity; его отказ даёт 503, а не доступ по старым claims. Код входа одноразовый, имеет срок и ограничение попыток; код/JWT не попадают в URL и логи.

SPA/API/WS имеют единый origin. Изменяющие запросы защищаются от CSRF, WS проверяет Origin. Локальный HTTP доступен только через loopback; исключение Secure для локального cookie не переносится во внешний профиль.
