# Одно сообщение — одна задача

Одно успешно обработанное Telegram-сообщение создаёт одну Pending-задачу: текст переносится непосредственно, голос — через транскрипцию. Разделение и переформулирование текста LLM не вводятся, поэтому соответствие входа и результата предсказуемо.

Бот принимает личные сообщения через long polling; на token работает один poller. Вход и outbox фиксируются до подтверждения приёма. При недоступном PostgreSQL offset не продвигается за несохранённое сообщение; повтор безопасен. Подтверждение update и ответ пользователю — разные действия.

Задача содержит текст, автора, статус и время создания. После создания меняется только статус; веб-создание, редактирование текста, удаление, исполнители и сроки не входят в текущий объём. Ошибка транскрипции не создаёт пустую карточку.
